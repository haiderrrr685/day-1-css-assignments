CSS controls how a webpage looks and how its content is arranged. In today's assignment, I practiced taking a plain document and giving it a clear visual order with headings, readable text, and enough space between sections.

Start with the content

Headings help readers see what each part is about. Paragraphs are easier to read when the line length and line spacing feel comfortable. A small set of colors can make important details stand out without making the page hard to follow.

Good spacing helps each part of a page feel easier to understand.

The box model

Every element can be thought of as a box. The content sits inside padding; a border can surround that padding; and margin adds room outside the border. Understanding those layers makes it easier to control the space between elements.

  • Content is the text, image, or other element inside the box.
  • Padding adds space between the content and its border.
  • Border outlines the element.
  • Margin creates space around the outside of the box.
